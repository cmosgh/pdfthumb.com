## Decisions Made

1. **admin.tsx not index.tsx for admin page** — An `index.tsx` inside a pathless group maps to the parent URL (`/dashboard`), not `/dashboard/admin`. Renaming to `admin.tsx` produces the correct URL path segment. This is a TanStack Router file-based routing convention.

2. **beforeLoad throws redirect silently** — No toast shown on admin redirect. The app has no toast system, and the existing codebase uses silent redirects throughout. Consistent with established patterns.

3. **Admin nav item is null, not disabled** — The plan specifies "hidden completely." `null` is the correct React idiom — the DOM element is absent entirely, not visible-but-disabled.

## Issues Encountered

The `npx tsc --noEmit` error `error TS2339: Property 'auth' does not exist on type '{}'` in the initial `route.tsx` was resolved once `routeTree.gen.ts` was regenerated via `vite build`. The root cause was that TanStack Router derives the `beforeLoad` context type from the generated route tree — the type is unavailable until the tree is regenerated with the new route. The `__root.tsx` already correctly used `createRootRouteWithContext<RouterContext>()` (applied in 02-03 commit `e38aa4c`).

Pre-existing `vitest.config.ts` TypeScript errors (missing `vitest` and `@vitejs/plugin-react` type declarations) were present before any changes and are out of scope — documented in 02-01 SUMMARY.
