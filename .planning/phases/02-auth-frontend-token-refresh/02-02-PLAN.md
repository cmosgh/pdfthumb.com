Create directory `src/routes/dashboard/_admin/` and two files inside it.

**`src/routes/dashboard/_admin/route.tsx`** — pathless layout route:

```typescript
import { createFileRoute, redirect, Outlet } from '@tanstack/react-router';

export const Route = createFileRoute('/dashboard/_admin')({
  beforeLoad: ({ context }) => {
    const auth = context.auth;

    // Unauthenticated → /login
    if (!auth?.isAuthenticated) {
      throw redirect({ to: '/login' });
    }

    // Authenticated but not admin → /dashboard (silent redirect, no toast — app has no toast system)
    if (!auth.user?.roles?.includes('ADMIN')) {
      throw redirect({ to: '/dashboard' });
    }
  },
  component: () => <Outlet />,
});
```

Important: The route ID string in `createFileRoute` MUST be `'/dashboard/_admin'` exactly — the underscore-prefixed directory name is pathless (not in URL). TanStack Router's `@tanstack/router-vite-plugin` will validate this against the generated route tree.
